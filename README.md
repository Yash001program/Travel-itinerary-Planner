# Personalized Travel Itinerary Planner (Skill Wallet Capstone Project 4)

A production-ready Streamlit application featuring:
1. **Configuration & User Preferences (Epic 3):** Secure API key entry for Google Gemini or Groq alongside an instant **Demo Mode** requiring zero external setup.
2. **Smart Destination Recommender (Epic 3):** Recommends top 3 matching cities based on mood, seasonal weather, party, and budget tier.
3. **Day-by-Day Optimized Itinerary Generator (Epic 4):** Geographically clustered daily plans with sequential time slots and live Local / USD / INR budget tracking.
4. **Vibe Customization & Dynamic Activity Swap (Epic 4):** Surgical single-slot or single-day regeneration without overwriting the rest of the itinerary.
5. **Trip Management & Offline PDF Export (Epic 5):** Simulated persistent trip history and 1-click offline PDF travel guide generation with an emergency contact checklist.

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
```
